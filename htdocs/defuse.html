Handleiding: Ontmantelen van de Bom

Inleiding tot het Ontmantelen

Gefeliciteerd, meesterbouwer! Nu je bom volledig is samengesteld, is het tijd om de procedures voor het ontmantelen ervan te begrijpen en te documenteren. Deze sectie zal gedetailleerd uitleggen hoe deelnemers de bom kunnen ontmantelen door vijf draden in een specifieke volgorde los te trekken. De juiste volgorde wordt bepaald door een heximale code, waarbij slechts één fout is toegestaan. Volg deze instructies zorgvuldig om ervoor te zorgen dat de bom realistisch en uitdagend is voor de deelnemers.

Draden en de Heximale Code

Bij het ontmantelen van de bom moeten de deelnemers vijf draden los trekken in een volgorde die wordt bepaald door een heximale code. De code geeft de juiste volgorde aan door groepen van 3 bits te gebruiken, te beginnen vanaf de minst significante bit (LSB).

Heximale Code Uitleg

  1. Heximale Code: De code wordt weergegeven als een hexadecimaal getal, bijvoorbeeld 1A3F.

  2. Binair Converteren: Zet de hexadecimale code om naar een binaire reeks.

  3. Groepen van 3 Bits: Begin vanaf de LSB en verdeel de binaire reeks in groepen van 3 bits. Elke groep bepaalt de volgorde van een draad.

Voorbeeld

Stel, de hexadecimale code is 388D.

  1. Zet 1A3F om naar binair: 0011 1000 1000 1101
  2. Verdeel deze reeks in groepen van 3 bits vanaf de LSB:
    • 101 (draad 5)
    • 001 (draad 1)
    • 010 (draad 2)
    • 100 (draad 4)
    • 011 (draad 3)
  3. De volgorde van los te trekken draden is dus: 5, 1, 2, 4, 3.

Ontmantelingsprocedure

  1. Lees de Heximale Code: Het display toont de hexadecimale code die de volgorde van de draden bepaalt.
  2. Binaire Conversie: De deelnemer moet de code omzetten naar binair en de volgorde van de draden bepalen zoals hierboven uitgelegd.
  3. Los Trekken van de Draden:
    • Trek de eerste draad in de volgorde los.
    • Wacht op een bevestiging (hoge piep goed, lage piep niet goed).
    • Trek de volgende draad los volgens de volgorde.
  4. Foutmarge: Eén foutieve draadtrekking is toegestaan zonder directe gevolgen, maar een tweede fout zal de bom activeren (in de vorm van een alarm of een ander signaal).

Voorzorgsmaatregelen

  • Kalmeer en Focus: Deelnemers moeten kalm blijven en gefocust werken. Paniek kan leiden tot fouten.
  • Dubbelcheck de Binaire Omzetting: Zorg ervoor dat de binaire omzetting correct is voordat je een draad los trekt.
  • Gebruik van Handschoenen: Aanbevolen om veiligheidshandschoenen te dragen om slippen te voorkomen bij het los trekken van draden.
